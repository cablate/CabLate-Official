# CabLate Visual References

這個資料夾保存已由使用者確認喜歡的視覺基準。它們不是待直接上線的網站圖片，而是後續 CSS、頁面 mockup 與 imagegen 產出的校準來源。

## Canonical references

- `open-desk-archive-desktop-reference.png`：桌機版完整長頁。約束左側固定導覽、紙面層次、內容密度、主視覺預留區與敘事性素材配置。
- `open-desk-archive-mobile-reference.png`：手機版完整長頁。約束精簡頂部列、單欄資訊順序、紙面容器、行動 CTA 與內容折疊方式。

## Non-negotiable design rules

- 保留 CabLate 的紫色有機主視覺方向，不另建第二套橘紅或暖色品牌。
- 以紙面、細框、輕陰影、少量有用途的素材層建立層次；元素不限定紙條或手寫註記，但必須有資訊用途。
- 各頁內容編排可以不同，導覽、字體、色彩、表面、圓角與陰影必須屬於同一套 Open Desk Archive 系統。
- 生成的 UI 圖先用於審核，不因為生成完成就自動成為網站正式素材。
